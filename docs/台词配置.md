# 台词配置（lines.json）

让小队员**不定时地自己说一句话**。

> **纯本地预设台词，不调用任何模型、不联网、零花费。**
> 台词都是人手写的，所以断网也能说话。想让它更活泼就多写几句。

---

## 1. 文件在哪

| 文件 | 作用 |
|---|---|
| `assets/lines.json` | **默认台词表**（包内，随版本更新） |
| `data/lines.json` | **你的覆盖文件**（首次运行自动生成一份副本） |

两层是**深合并**的：你在 `data/lines.json` 里写了哪个键，就覆盖哪个键；没写的沿用默认。

右键宠物 →「**打开配置文件夹**」就能看到 `lines.json`。
改完存盘 → 右键宠物 →「**重载配置**」**立刻生效，不用重启**。

> 想立刻听一句验证改对了没有：右键 →「**让它说一句**」。

---

## 2. 完整字段

```jsonc
{
  "enabled": true,              // 总开关。false = 完全不主动说话
  "showSec": 8,                 // 每句话的气泡显示几秒

  "intervalMinSec": 90,         // 说完后随机等 [min, max] 秒再说下一句
  "intervalMaxSec": 300,        //   想热闹就 20~60；想安静就 600~1800

  "quietAfterInteractionSec": 25, // 你刚点过/拖过它之后，这段时间内不主动说话
  "noRepeat": 8,                // 最近说过的 N 句不再重复

  "lines": [                    // 【主池】待机时随机说的
    "先备份，再动手。",
    "现在是 {time}，还没睡？"
  ],

  "lateNight": {                // 【深夜池】只在 fromHour ~ toHour 之间参与抽取
    "enabled": true,
    "fromHour": 0,              //   跨午夜也行：比如 22 ~ 5
    "toHour": 6,
    "lines": ["这个点了，靶场明天还在。"]
  },

  "states": {                   // 【场景池】外部通过接入口推状态时顺带说一句
    "thinking": ["让我想想这条链路怎么走。"],
    "working":  ["正在跑，稍等片刻。"],
    "error":    ["失败……这个报错我没见过。"],
    "done":     ["搞定，收工。"]
  },

  "clicks": [                   // 【点击池】被点一下的时候说的
    "别戳了，痒。"
  ]
}
```

---

## 3. 占位符

台词里可以写这几个，说话时会自动替换：

| 占位符 | 替换成 | 例子 |
|---|---|---|
| `{time}` | 当前时间 HH:MM | `"现在是 {time}。"` → `现在是 20:22。` |
| `{date}` | 今天日期 YYYY-MM-DD | `"今天是 {date}。"` |
| `{name}` | 宠物名（取 `config.json` 的 `pet.name`） | `"我是 {name}。"` |

---

## 4. 什么时候它会说话

| 时机 | 用哪个池 | 受"避让窗口"限制吗 |
|---|---|---|
| 每 `intervalMinSec~intervalMaxSec` 秒随机一次 | `lines`（+ 深夜时叠加 `lateNight.lines`） | 受限 |
| 被左键点一下 | `clicks` | **不受限**（点了就说） |
| 外部框架推状态（`POST /state`） | `states[状态名]` | **不受限** |
| 菜单「让它说一句」/ `POST /chatter` | `lines` | **不受限** |
| 窗口隐藏时 | —— | 一律不说 |

另外：**同一句话在最近 `noRepeat` 句之内不会重复**（池子不够大时会退化为允许重复）。

---

## 5. 和"接模型对话"的区别

这个功能**刻意不接任何模型**：

|  | 本功能（预设台词） | 接模型生成 |
|---|---|---|
| 花钱 | **0 元** | 每次都要钱 |
| 断网 | 照常说 | 说不了 |
| 延迟 | 0 | 有 |
| 内容可控 | **完全可控**（你写什么它说什么） | 会跑偏 |

想接"真正会对话"的 AI，用接入口那条路：由**你的程序**生成文字，再 `POST /say` 推给它显示
（见 [`接入口.md`](接入口.md)）。桌宠本身永远只是个"显示 + 表演"的壳。

## 6. 常见问题

| 现象 | 原因 |
|---|---|
| 改了配置完全没反应 | **大概率是文件带了 UTF-8 BOM**。PowerShell 的 `Set-Content -Encoding UTF8`、记事本"UTF-8 带 BOM"都会写 BOM，`JSON.parse` 会直接失败。程序会在日志里明确报出来（`配置文件解析失败，这一份会被忽略`）。修法：另存为 **UTF-8（无 BOM）**，或用 `[System.IO.File]::WriteAllText($p,$s,(New-Object System.Text.UTF8Encoding($false)))` |
| JSON 语法错误 | 多余逗号、中文引号 `“”`、少了括号都会导致整份文件被忽略。日志里会指出原因 |
| 一句话都不说 | 检查 `enabled` 是不是 false；`lines` 是不是空数组；窗口是不是被隐藏了 |
| 老说同一句 | 把池子写大一点，或调大 `noRepeat` |
| 太吵 | 把 `intervalMinSec/MaxSec` 调大（比如 `600` / `1800`），或直接 `"enabled": false` |
| 深夜台词不出现 | 确认当前小时落在 `[fromHour, toHour)` 内（跨午夜写成 `22` / `5`） |

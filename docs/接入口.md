# 接入口 —— 让别的框架驱动这只桌宠

桌宠本体**不认识任何框架**：它不 import 谁，也不被谁 import。
唯一的耦合面就是这块本地 HTTP 接口。今天不接任何东西它照样能用；
明天想接 PI、接别的智能体、接你自己的脚本，都从这里进。

> **这里没有任何模型调用。** `/say` 只是把外部推来的文字显示出来，
> 桌宠自己**不生成**任何文字，所以**零 API 花费**。

---

## 1. 地址与端口

```
http://127.0.0.1:8977
```

- 只绑 **回环地址**，不对外网开放
- 端口被占用会自动往后顺延（8978、8979…）；**真实端口**用 `GET /state` 里的 `busPort` 查
- 整体开关：配置里的 `"bus": { "enabled": false }`

```powershell
curl.exe -s http://127.0.0.1:8977/health
# { "ok": true, "app": "redteam-pet-desktop", "pid": 16288 }
```

---

## 2. 接口一览

| 方法 | 路径 | Body | 说明 |
|---|---|---|---|
| GET | `/health` | — | 存活探测 |
| GET | `/state` | — | 当前状态 / 动画 / 可用动作 / 窗口坐标 / 端口 |
| GET | `/anims` | — | 素材目录里实际存在的动作名 |
| POST | `/state` | `{"state":"working","holdSec":8}` | 切语义状态 |
| POST | `/play` | `{"anim":"写代码","once":true}` | 直接播某个动作 |
| POST | `/say` | `{"text":"...","sec":10}` | 冒气泡 |
| POST | `/chatter` | `{"kind":"idle","force":true}` | 让它从**本地台词表**里随便说一句（不用你给文字，也不调模型）。`kind` 可选 `idle` / `clicks` / 状态名 |
| POST | `/visible` | `{"visible":false}` | 显示 / 隐藏 |
| POST | `/debug/capture` | `{"path":"D:/x.png"}` | 窗口截图落盘 |

出错时返回 4xx/5xx，body 是 `{"message":"..."}`。

> **`/say` 与 `/chatter` 的区别**：`/say` 是你给文字、它只负责显示；
> `/chatter` 是让它从自己那份手写的 `lines.json` 里挑一句说。
> 两者都**不联网、不调模型、零花费**。想要"会对话的 AI"，由你的程序生成文字后 POST `/say`。

### 语义状态

| state | 默认动作 | 典型用途 |
|---|---|---|
| `idle` | 待机呼吸休闲 | 无事发生 |
| `thinking` | 工作状态-思考冒泡 | 模型在推理 / 任务在排队 |
| `working` | 工作状态-忙碌点按 | 正在跑构建、跑测试、跑批处理 |
| `error` | 工作状态-垂头叹气冒汗 | 失败、异常 |
| `done` | 点击回应-开心跃动 | 完成 |

- 非 `idle` 状态会**锁定** `holdSec` 秒（默认取配置的 `timing.stateHoldSec`），
  期间待机随机动作**不会**来抢镜；到点自动回 `idle`。
- 映射关系在 `assets/config.json` 的 `animations.states` 里，想换动作改那里。
- **手动交互优先**：状态锁定期间你点一下宠物，会立刻解除锁定播点击回应。
- 推状态时它会**顺带说一句**该场景的台词（`lines.json` 的 `states` 池），
  且不受"刚被点过就不说话"的避让限制 —— 外部事件优先。

## 3. 调用示例

### ⚠ PowerShell 用户先看这条

PowerShell 把 JSON 传给 `curl.exe` 时**会吃掉引号**，直接写 `-d '{"a":1}'` 多半报：

```
{ "message": "JSON 解析失败：Expected property name or '}' ..." }
```

**稳妥写法**：把 body 写进文件，再 `--data-binary "@文件"`。

```powershell
$body = '{"state":"working","holdSec":600}'
[System.IO.File]::WriteAllText("$env:TEMP\body.json", $body, (New-Object System.Text.UTF8Encoding($false)))
curl.exe -s -X POST -H 'Content-Type: application/json' --data-binary "@$env:TEMP\body.json" http://127.0.0.1:8977/state
```

或者干脆用 PowerShell 自己的 `Invoke-RestMethod`（不碰引号问题）：

```powershell
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8977/state `
  -ContentType 'application/json' -Body '{"state":"working","holdSec":600}'
```

### Node.js

```js
const BASE = 'http://127.0.0.1:8977';
const post = (p, body) => fetch(BASE + p, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(body),
}).then((r) => r.json());

await post('/state', { state: 'working', holdSec: 600 });   // 开始干活
// ...你的任务...
await post('/state', { state: 'done' });                    // 干完了
```

### Python

```python
import requests
BASE = "http://127.0.0.1:8977"
requests.post(f"{BASE}/state", json={"state": "working", "holdSec": 600})
print(requests.get(f"{BASE}/state").json())
```

### 命令行 / 任何语言

只要能把一段 JSON POST 到 `http://127.0.0.1:8977/state` 就行，没有别的约定。

## 4. 接一个智能体的典型形态

真正的"对话内容"由**你的框架**决定，桌宠只负责演：

```js
// 伪代码：接任意 agent 框架
async function onAgentEvent(ev) {
  switch (ev.type) {
    case 'thinking':  return post('/state', { state: 'thinking', holdSec: 30 });
    case 'tool_call': return post('/state', { state: 'working',  holdSec: 120 });
    case 'error':     return post('/state', { state: 'error',    holdSec: 10 });
    case 'done':      return post('/state', { state: 'done' });
    case 'message':   return post('/say',   { text: ev.text, sec: 12 }); // 想说话就推文字
  }
}
```

要点：

- **状态是"幂等语义"，不是命令队列** —— 重复推同一个状态没有副作用。
- `holdSec` 给"最坏情况还要多久"，中途可以再推一次把它续上。
- 不想显示任何文字，就永远别调 `/say`，桌面版完全没有碎碎念。

## 5. 排查

| 现象 | 处理 |
|---|---|
| 连不上 8977 | `curl http://127.0.0.1:8977/health`；不通就看 `GET /state` 是否可用（可能需要顺延端口），或配置里 `bus.enabled` 被关了 |
| 报 `JSON 解析失败` | PowerShell 引号问题，见上面第 3 节 |
| `{"message":"未知状态：xxx"}` | 状态名只能是 `idle/thinking/working/error/done`，或你在 `animations.states` 里自定义的键 |
| `{"message":"没有这个动作：xxx"}` | 素材名要对得上 `assets/webm/<名字>.webm`，用 `GET /anims` 看全部可用名 |
| 推了状态但宠物没反应 | 看是不是被手动点击/拖拽解除了锁定；再 `GET /state` 看 `state` 和 `animation` 是否已变 |
